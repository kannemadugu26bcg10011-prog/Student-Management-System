Student Management System
A simple Student Management System developed using Python. This project allows users to add, view,
search, and delete student records and also view class performance details.
Tech Stack
Language: Python 3.7+
Modules: json, os
External Libraries: None
How to Run
1. Clone the Repository
git clone https://github.com//student-management-system.git
cd student-management-system
2. Run the Program
python main.py
Features
Add Student Record
View All Students
Search Student by Roll Number
View Class Performance Summary
Delete Student Record
Exit the Program

About the Project
This project is a basic Python application created to manage student records efficiently. It uses a JSON
file
to store the student data, so the records can be saved and accessed when the program is run again.
